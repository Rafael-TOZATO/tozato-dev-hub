# 🤝 Guia de Contribuição & Diretrizes de Governança

Agradecemos o interesse em contribuir para este projeto! Para manter a qualidade do código, a rastreabilidade e os padrões de engenharia, siga este fluxo de trabalho.

---

## 🛠️ Como Contribuir

### 1. Reportando Bugs ou Sugerindo Melhorias
* Antes de iniciar qualquer alteração, navegue até a aba **Issues** do repositório.
* Verifique se o problema ou melhoria já foi reportado por outro colaborador.
* Caso não encontre, abra uma nova **Issue** descrevendo com clareza o comportamento esperado, logs relevantes e o ambiente de execução.

### 2. Fluxo de Trabalho Git (Branch & Commits)
* **Fork / Branch:** Crie uma branch dedicada a partir da branch principal (`main`):
  ```bash
  git checkout -b feature/nome-da-sua-feature
  # ou para correções de bug:
  git checkout -b fix/descricao-do-bug
