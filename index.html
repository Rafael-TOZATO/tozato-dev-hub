# TozatoCode-AI Site Aplicação web interativa para centralização de portfólio profissional, listagem dinâmica de repositórios via GitHub API e assistente conversacional integrado, com arquitetura corrigida após incidente de exposição de credencial. - **Repositório:** [Rafael-TOZATO/tozatocode-ai-site](https://github.com/Rafael-TOZATO/tozatocode-ai-site) - **Site publicado:** [rafael-tozato.github.io/tozatocode-ai-site](https://rafael-tozato.github.io/tozatocode-ai-site/) ## Sumário - [Status Atual](#status-atual) - [Funcionalidades](#funcionalidades) - [Arquitetura](#arquitetura) - [Segurança](#segurança) - [Tecnologias Utilizadas](#tecnologias-utilizadas) - [Estrutura do Repositório](#estrutura-do-repositório) - [Configuração e Deploy](#configuração-e-deploy) - [Fluxo de Contribuição](#fluxo-de-contribuição) - [Documentação Adicional](#documentação-adicional) - [Licença](#licença) - [Contato](#contato) ## Status Atual | Item | Situação | |---|---| | Chave de API removida do código-fonte | Corrigido no `index.html` distribuído neste repositório | | Push da correção para a branch `main` | Pendente de confirmação — verificar `index.html` publicado | | Busca pública de repositórios (`repos`) | Operante, independe do proxy | | Chat com IA via proxy serverless | Depende do deploy do Worker e da atualização de `PROXY_ENDPOINT` | ## Funcionalidades - Exibição em tempo real de dados do perfil do GitHub. - Listagem e filtragem de repositórios públicos via GitHub REST API. - Seção consolidada de links profissionais e canais de contato. - Interface de chat interativa conectada a um serviço intermediário (proxy) que processa as requisições ao modelo de linguagem sem expor credenciais no navegador. ## Arquitetura A versão anterior realizava chamadas diretas do front-end à API do Gemini, com a chave de API declarada em texto plano no arquivo `index.html`. Essa prática expôs a credencial a qualquer visitante do site e a varreduras automatizadas de vazamento de segredos (secret scanning), resultando em revogação automática pelo GitHub e pelo Google Cloud. A arquitetura atual segue o padrão de **proxy de backend**: ``` Navegador (GitHub Pages) → Proxy serverless (Cloudflare Workers) → API Gemini index.html server/gemini-proxy/index.js ``` - O front-end nunca tem acesso à chave da API. - A chave é armazenada como *secret* no ambiente do Cloudflare Workers (`wrangler secret put`), fora do controle de versão. - O proxy valida a origem da requisição (`Access-Control-Allow-Origin` restrito ao domínio do GitHub Pages) e limita o tamanho da mensagem recebida. Detalhes completos em [`docs/INCIDENTE_SEGURANCA.md`](docs/INCIDENTE_SEGURANCA.md). ## Segurança Políticas de divulgação de vulnerabilidades, gestão de segredos e resposta a incidentes estão descritas em [`SECURITY.md`](SECURITY.md). ## Tecnologias Utilizadas - HTML5, CSS3 / Tailwind CSS - JavaScript (ES6+) / TypeScript - GitHub REST API - GitHub Pages (hospedagem do front-end) - Cloudflare Workers (proxy serverless para a API Gemini) - GitHub Actions (varredura automatizada de segredos) ## Estrutura do Repositório ``` tozatocode-ai-site/ ├── index.html ├── README.md ├── SECURITY.md ├── CONTRIBUTING.md ├── LICENSE ├── .gitignore ├── .env.example ├── docs/ │ ├── INCIDENTE_SEGURANCA.md │ ├── JORNADA.md │ └── FLUXO_VERSIONAMENTO.md ├── server/ │ └── gemini-proxy/ │ ├── index.js │ └── wrangler.toml └── .github/ ├── CODEOWNERS ├── PULL_REQUEST_TEMPLATE.md └── workflows/ └── secret-scan.yml ``` ## Configuração e Deploy 1. Publicar `index.html` e demais arquivos estáticos via GitHub Pages (branch `main`, diretório raiz). 2. Deploy do proxy: dentro de `server/gemini-proxy`, executar `wrangler deploy` (requer conta Cloudflare e Wrangler CLI configurados). 3. Definir o segredo em ambiente do Worker: `wrangler secret put GEMINI_API_KEY`. 4. Atualizar a constante `PROXY_ENDPOINT` em `index.html` com a URL gerada pelo Worker. ## Fluxo de Contribuição Regras de branches protegidas, revisão obrigatória e processo de pull request estão descritas em [`CONTRIBUTING.md`](CONTRIBUTING.md) e detalhadas em [`docs/FLUXO_VERSIONAMENTO.md`](docs/FLUXO_VERSIONAMENTO.md). ## Documentação Adicional - [Jornada de desenvolvimento autodidata](docs/JORNADA.md) - [Relatório do incidente de segurança](docs/INCIDENTE_SEGURANCA.md) - [Fluxo de versionamento e branches protegidas](docs/FLUXO_VERSIONAMENTO.md) ## Licença Distribuído sob licença MIT.
